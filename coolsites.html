Cool Websites
Here's a list of cool websites I've found throughout my time on the internet. Some of these are useful tools for creating stuff. Others are websites that I just think are cool.

If you specifically want Bryce resources, go to this page!
  • Ultrabox Sample Extractor - extracts wave files from soundfont files.
  • NTSC-RC - cool vhs effects and filters.
  • Shikoshib's Winerr - windows error maker. Includes a bunch of windows os's.
  • Adguard Files - list of clean uncracked windows software.
  • CoolText - text generator including animated red burning text.

  • Bart Bash - possibly the best game ever.
  • Unsweeetened - revived old school south park wallpapers and renders.
  • Sweeet.com via Wayback Machine - og site that hosted a shit ton of south park content.
  • Guyhilism - insanely awesome art site.
  • Spinebreaker - another incredible website.
  • Jan Ternald's - old super detailed bryce artist.

  • Winamp Museum - collection of winamp themes.
  • 88x31 Collection - bunch of images like the one at the end of this page.
  • wiby - bunch of random old nostalgic websites.
